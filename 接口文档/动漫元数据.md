# 动漫播放管理


## 获取动漫详情


**接口地址**:`/api/metadata/play/{id}`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:<p>根据动漫ID获取动漫的基本信息，包括名称、封面、简介、评分、制作公司等。不包含播放源信息。</p>



**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|id|动漫ID（本地数据库ID）|path|true|integer(int32)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|获取成功|AnimeDetailDTO|
|400|Bad Request|ResultVoid|
|401|Unauthorized|ResultVoid|
|404|动漫不存在|ResultVoid|
|405|Method Not Allowed|ResultVoid|
|500|Internal Server Error|ResultVoid|
|502|Bad Gateway|ResultVoid|
|503|Service Unavailable|ResultVoid|


**响应状态码-200**:


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|id|动漫ID（Bangumi ID）|integer(int32)|integer(int32)|
|nameCn|中文名称|string||
|name|原始名称|string||
|nameCnAliases|中文名称别名|string||
|imagesLarge|封面图URL（大图）|string||
|summary|简介|string||
|airDate|播出日期|string||
|platform|平台类型：TV/OVA/剧场版/WEB|string||
|studio|制作公司|string||
|score|评分|number||
|episodes|章节数|integer(int32)|integer(int32)|
|tags|标签列表|array|array|
|metaTags|元标签列表|array|array|

## 获取动漫播放源


**接口地址**:`/api/metadata/play/{id}/sources`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:<p>根据动漫ID获取多播放源的m3u8地址。播放源从各采集站获取，支持量子、新浪、无尽等资源站。返回所有播放源及其有效集数。</p>



**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|id|动漫ID（本地数据库ID）|path|true|integer(int32)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|获取成功|PlaySourceDTO|
|400|Bad Request|ResultVoid|
|401|Unauthorized|ResultVoid|
|404|动漫不存在|ResultVoid|
|405|Method Not Allowed|ResultVoid|
|500|Internal Server Error|ResultVoid|
|502|Bad Gateway|ResultVoid|
|503|Service Unavailable|ResultVoid|


**响应状态码-200**:


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|sourceName|播放源名称，如：量子、新浪、无尽|string||
|sourceKey|播放源标识，如：liangzi、xinlang、wujin|string||
|episodes|该播放源的全部集数列表|array|EpisodeDTO|
|&emsp;&emsp;episodeName|集数名称，如：第01集、第1集|string||
|&emsp;&emsp;m3u8Url|m3u8播放地址|string||
|success|解析是否成功|boolean||
|errorMessage|失败原因（如果解析失败）|string||


**响应示例**:
```javascript
{
```

# 动漫元数据管理


## 设置管理员推荐


**接口地址**:`/api/metadata/admin/recommend`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>管理员将指定的动漫ID列表存入Redis，用于首页推荐展示。推荐数据有效期为7天。</p>



**请求示例**:


```javascript
{
  "animeIds": [],
  "position": "home_banner"
}
```


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|adminRecommendDTO|推荐请求参数|body|true|AdminRecommendDTO|AdminRecommendDTO|
|&emsp;&emsp;animeIds|要推荐的动漫ID列表||true|array|integer(int32)|
|&emsp;&emsp;position|推荐位置标识||false|string||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|设置成功|ResultVoid|
|400|Bad Request|ResultVoid|
|401|Unauthorized|ResultVoid|
|403|权限不足，需要管理员权限|ResultVoid|
|404|Not Found|ResultVoid|
